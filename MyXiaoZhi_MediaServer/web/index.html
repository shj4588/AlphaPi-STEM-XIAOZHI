AlphaPi（小智）设备同一个地址，按客户端自动转码
—
小智固件没有 mp3 解码器（flac/aac 更不行），音频通路只认 8bit / 24000Hz / 单声道。 所以凡是被认成小智的请求，服务端都会现用 ffmpeg 解码重采样，包 44 字节 WAV 头（长度字段 0xFFFFFFFF）推流； R1 那条路一个字节都不变。
识别方式三选一：① 直接用 /ap/ 前缀（最稳，固件不发 UA 也不会认错） ② URL 带 ?dev=ap ③ UA 里带 alphapi / xiaozhi / esp32 / espressif。
电台默认不转码，地址原样给 MP3（需要 WAV 时加 ?fmt=wav）。
